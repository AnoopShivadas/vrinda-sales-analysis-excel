An interactive **Excel dashboard** built to analyze Vrinda Store sales data and uncover insights related to customer behavior, order trends, and sales performance.

## 📌 Overview

This project focuses on transforming raw sales data into meaningful business insights using Microsoft Excel dashboards and visual analytics.

### Focus Areas
- Monthly sales & order trends
- Customer demographics analysis
- Channel-wise sales performance
- Order status tracking
- Regional sales insights

## ❓ Problem Statement

Businesses often struggle to:
- Understand monthly sales patterns
- Track customer demographics and purchasing behavior
- Identify top-performing regions
- Compare sales across multiple channels
- Analyze order delivery and return patterns

This dashboard addresses these challenges using interactive Excel-based analytics.

## 📊 Dashboard Features

- Monthly Sales vs Orders analysis
- Men vs Women sales distribution
- Order status breakdown
- Top 5 states by sales
- Age group vs gender analysis
- Sales by channels (Amazon, Flipkart, Myntra, etc.)
- Interactive slicers & filters

## 🔍 Key Insights

- 👩 Women contribute significantly higher sales than men
- 📦 Majority of orders are successfully delivered (~90%+)
- 📍 Maharashtra and Karnataka are top-performing states
- 🛒 Amazon and Myntra generate the highest sales
- 👥 Adult age group dominates overall order volume
